洪水清漂船

操作说明

  • ↑ / ↓：调整航速油门（含倒车）；← / →：转向
  • W / S：放缆 / 收缆，缆越长张力越小但机动变差
  • 空格 或 G：抓斗抓取船头扇形范围内最近的漂浮物
  • P/Esc：暂停；R：同 seed 重开；N：新开一局并校验布局
  • K：手动从最近检查点恢复；碰撞/搁浅也会自动恢复，均无需刷新页面
  • 浮木、芦苇束为普通垃圾，危化桶 ☣ 为危险物，漏掉 3 件即失败
  • 拖曳重量超过缆绳容量会断裂；撞桥墩/搁浅会从检查点恢复
  • 把垃圾拖到右侧回收点卸货，集齐三类配额即获胜

地图、任务与障碍均由同一固定 seed 生成；结束摘要写入 localStorage 键 cleanup-boat-summary-v1，可在 DevTools Console 查看 JSON.parse(localStorage.getItem('cleanup-boat-summary-v1'))。
